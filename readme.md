# 🌍 Polyvox — AI-Powered Language Translation Tool

Polyvox is a simple and modern language translation application built using **Python, Streamlit, and LibreTranslate API**.

It allows users to enter text, select a source language and target language, and instantly translate the text through a clean and user-friendly interface.

---

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Swap source and target languages
- 🏳️ Language flags for easy identification
- ⚡ Fast translation using LibreTranslate
- 🎨 Modern dark-themed user interface
- 💻 Simple and beginner-friendly design
- 🛡️ Error handling for failed translation requests

---

## 🖥️ User Interface

Polyvox provides a clean interface where users can:

1. Select the **source language**
2. Select the **target language**
3. Enter the text to translate
4. Click **Translate**
5. View the translated result
6. Use the **Swap** button to switch languages

---
